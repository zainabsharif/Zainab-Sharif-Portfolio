## About

I'm a web developer who treats design as part of the function, not an add-on. Every site I build is themed around the brand or project behind it — visuals, interactions, and structure working together, not just a working backend underneath.

This repository is the source for my personal portfolio, showcasing selected projects across full-stack, frontend, and game development.
